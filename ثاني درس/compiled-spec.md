# Compiled Specification — Lesson 02: Complete Skeletal System (Axial + Appendicular)

## Scientific Verification Summary

### Official Curriculum Facts (Ministry Textbook)
1. **Total Bones in Adult Human Skeleton**: `206`
2. **Skeletal System Components**: `5` (العظام، الغضاريف، المفاصل، الأربطة، الأوتار)
3. **Vertebral Column Vertebrae**: `33` (7 عنقية، 12 ظهرية/صدرية، 5 قطنية، 5 عجزية ملتحمة، 4 عصعصية ملتحمة)
4. **Vertebral Column Bones (after fusion)**: `26` (7 عنقية + 12 ظهرية + 5 قطنية + 1 عجزية + 1 عصعصية)
5. **Skull Bones**: `22` (8 بالجزء الخلفي/المخي + 14 بالجزء الأمامي/الوجهي) - Note: Excludes 6 auditory ossicles in official count.
6. **Thoracic Cage Bones**: `37` (12 فقرة صدرية + 24 ضلعاً + 1 عظيمة القس)
7. **Rib Pairs**: `12` زوجاً (10 أزواج متصلة بالقس منها 2 أزواج عائمة غير متصلة مباشرة والقس).
8. **Appendicular Skeleton Total**: `126` (الحزام الصدري 4 + الطرف العلوي 60 + الحزام الحوضي 2 + الطرف السفلي 60)
9. **Pectoral Girdle**: `4` (الترقوة × 2 + لوح الكتف × 2)
10. **Upper Limb (per limb / both limbs)**: `30` / `60` (العضد 1 + الزند والكعبرة 2 + الرسغ 8 + راحة اليد 5 + السلاميات 14)
11. **Pelvic Girdle**: `2` (عظمتا حوض، كل منها ناتجة عن التحام الحرقفة + الوركي + العانة جنينياً)
12. **Lower Limb (per limb / both limbs)**: `30` / `60` (الفخذ 1 + الرضفة 1 + القصبة والشظية 2 + رسغ القدم 7 + مشط القدم 5 + السلاميات 14)

### Disputed / Non-Standard Scoring Rules
- In quizzes, questions testing total axial skeleton bones must handle ambiguity clearly: `80` bones is standard official axial count (Skull 29/22 + Vertebral column 26 + Rib cage 25 = 80 or 22+26+37=85 depending on overlap). Therefore, questions involving overlapping counts MUST explicitly define the boundary (e.g. "عدد عظام الهيكل المحوري بشكل مستقل دون تكرار القفص الصدري والعمود الفقري").
- No single disputed option is marked as strictly penalty-inducing if multiple valid textbook interpretations exist.
- Appendicular breakdown (fact 8-12 above) is internally consistent with the `80` axial figure already used throughout the lesson: `126 + 80 = 206`. As with the axial figures, granular sub-counts (carpals/tarsals/phalanges) follow the standard anatomical convention; no alternate textbook variant was found for these, so none are flagged `NEEDS_SOURCE_VERIFICATION`.
